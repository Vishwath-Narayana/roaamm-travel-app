# Motion

ROAAMM's motion should feel physical and intentional: few movements, all of
them smooth. Everything here is plain CSS, the Web Animations API and small
React hooks. There are no animation or scroll libraries.

The values live in `packages/design-tokens` (source of truth), are mirrored as
CSS variables in `apps/web/src/styles/tokens.css`, and as numbers for
JavaScript in `apps/web/src/motion/tokens.ts`. Tests keep the three in sync.

## Easings

| Token | Value | Use it for |
|---|---|---|
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` | Entrances and most transitions: fast start, soft landing |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)` | Things that move from one place to another (indicators, carousels) |
| `--ease-in` | `cubic-bezier(.7, 0, .84, 0)` | Exits only (leaving the screen) |
| `--ease-spring` | `linear(...)` spring, one gentle overshoot (about 4%) | Small controls: press release, toggles, toasts |

`--ease-spring` is generated by `scripts/gen-spring.mjs` (a damped spring,
damping ratio 0.72) and written to `packages/design-tokens/spring.gen.ts`.
Browsers without `linear()` get the fallback `cubic-bezier(.34, 1.36, .64, 1)`
through `@supports`.

## Durations

| Token | Value | Use it for |
|---|---|---|
| `--dur-press` | 90 ms | Press down (buttons scale to .97) |
| `--dur-hover` | 180 ms | Hover and focus feedback, colour fades |
| `--dur-ui` | 240 ms | Small UI: toggles, icons, menus, tab indicator |
| `--dur-content` | 450 ms | Content entering: reveals, panels, toasts |
| `--dur-section` | 700 ms | Large surfaces: section-level reveals, photo crossfades |
| `--dur-hero` | 1100 ms | The hero intro only |
| `--stagger` | 60 ms | Delay between items in a group |

## Rules

- **Compositor only.** Animate `transform` (and `translate`, `scale`,
  `rotate`), `opacity`, `clip-path` and `filter`. The one layout exception is
  the `grid-template-rows: 0fr` to `1fr` height trick (FAQ). Never animate
  width, height, top, left, margin or box-shadow blur.
- **Exits are shorter.** About 0.6x the entrance.
- **Nothing interactive takes longer than 450 ms.** Only ambient motion (the
  hero's scroll zoom) may run longer than 1.2 s.
- **Choreography.** Stagger 40 to 80 ms per item, total stagger at most
  600 ms. Entrances travel 12 to 24 px. Scale never below 0.96. Overshoot only
  on small controls.
- **Reduced motion wins.** With `prefers-reduced-motion: reduce` or the footer
  toggle (`data-motion="reduced"` on `<html>`), every duration is zero, nothing
  autoplays, there is no parallax and no ambient loop: final states show at once.
- **Hover is for mice.** Hover effects live inside
  `@media (hover: hover) and (pointer: fine)`, and each one has a matching
  `:focus-visible` effect.
- **Off screen means paused.** Ambient animations and `requestAnimationFrame`
  loops stop when their element is out of view or the tab is hidden.
- **`will-change` only while moving.** Add it when an animation starts and
  remove it when it ends.
- **No scroll hijacking.** Normal browser scrolling; `scroll-behavior: smooth`
  only for in-page anchor links, and not under reduced motion.
