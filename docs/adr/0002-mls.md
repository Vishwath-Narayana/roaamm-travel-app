# ADR 0002: MLS (RFC 9420) for group end-to-end encryption

Status: accepted

## Context
Chats are 1:1 and group (up to 256 members), with multiple devices per user.

## Decision
Use OpenMLS compiled to WebAssembly. The Room DO is the Delivery Service and orders commits. The Java core is the Authentication Service. Calls derive SFrame keys from the MLS exporter.

## Consequences
- Standard, reviewed protocol with forward secrecy and post-compromise security.
- Group changes cost log(n) work.
- Browser-delivered JavaScript remains a trust limit. It is stated in `docs/security.md`.
