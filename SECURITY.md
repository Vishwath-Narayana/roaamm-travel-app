# Security policy

ROAAMM is a portfolio project. It uses only simulated data and Razorpay test mode.

## Reporting a vulnerability

Please open a private security advisory on GitHub ("Security" tab, "Report a vulnerability") instead of a public issue. Include steps to reproduce and the affected URL or file. I aim to reply within 7 days.

## Scope

- In scope: `roaamm.plinthwell.com`, `roaamm-rt.plinthwell.com`, `roaamm-api.plinthwell.com`, `roaamm-status.plinthwell.com` and this repository.
- Out of scope: denial-of-service tests, social engineering, and other `plinthwell.com` hosts.

## Design notes

The threat model, including the honest limitation of browser-based end-to-end encryption, is in [docs/security.md](docs/security.md).
